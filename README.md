# omomuro.dev

Kazuhiro Itoの個人ポートフォリオサイトです。

## 🌟 概要

このサイトは、Software EngineerのKazuhiro Itoの作品や経歴、読書記録などを紹介するポートフォリオサイトです。

## 🚀 主な機能

- **自己紹介ページ** - プロフィール、経歴、スキルセットの紹介
- **作品紹介** - iPhoneアプリ、ゲーム、Webサービスなどの制作物
- **本棚** - 読んだ本の記録と感想
- **ギャラリー** - 写真やイラストの展示
- **ラボ** - 実験的なプロジェクトや技術検証

## 🛠 技術スタック

### フロントエンド
- **Next.js 15** - Reactベースのフルスタックフレームワーク
- **React 19** - UIライブラリ
- **TypeScript** - 型安全な開発
- **Tailwind CSS** - ユーティリティファーストのCSSフレームワーク
- **Framer Motion** - アニメーションライブラリ

### UI/UX
- **Headless UI** - アクセシブルなUIコンポーネント
- **Radix UI** - プリミティブなUIコンポーネント
- **Heroicons** - アイコンライブラリ
- **React Simple Icons** - ブランドアイコン

### アニメーション・インタラクション
- **GSAP** - 高性能アニメーションライブラリ
- **Rive** - インタラクティブアニメーション
- **Three.js** - 3Dグラフィックス

### その他
- **Gray Matter** - Markdownのフロントマター解析
- **React Markdown** - Markdownレンダリング
- **Date-fns** - 日付操作ライブラリ
- **Sharp** - 画像最適化

## 📦 セットアップ

### 必要な環境
- Node.js >= 22.14.0
- npm >= 10.9.2

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/your-username/omomuro.dev.git
cd omomuro.dev

# 依存関係をインストール
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてサイトを確認できます。

## 🔧 利用可能なスクリプト

```bash
# 開発サーバーの起動
npm run dev

# プロダクションビルド
npm run build

# プロダクションサーバーの起動
npm start

# ESLintによるコードチェック
npm run lint

# Prettierによるコードフォーマット
npm run format
```
